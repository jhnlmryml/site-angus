# 🛡️ Site VIP | Angus Shield

Simple, fast, and mobile-first job management and accounting platform built for Australian tradies. Designed to give instant financial clarity with zero complexity.

---

## ⚡ Key Features

* **30-Second Mobile Usability**: Built for fast, effortless site usage on phones
* **Single Screen Metrics**: Real-time view of money in, money out, and net profit.
* **Dark Mode UI**: Optimized contrast for outdoor visibility and battery savings
* **Bank-Grade Security**: Powered by Supabase Auth and Row-Level Security (RLS)

---

## 🛠️ Tech Stack

* **Framework**: Next.js 
* **Language**: TypeScript
* **Database & Auth**: Supabase
* **Styling**: Tailwind CSS 
* **Deployment**: Vercel

---

## 🚀 Quick Start

### 1. Environment Setup

Create `.env.local` in the root folder:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
